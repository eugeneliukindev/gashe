# Security policy

## Supported versions

The latest release of each module: gashe, backend/redis, codec/msgpack and compress/zstd. Fixes
are not backported.

## Reporting a vulnerability

Report it privately through [GitHub](https://github.com/eugeneliukindev/gashe/security/advisories/new),
not in a public issue. Include the version, a program that shows the problem and its impact.
